Project plan

The layout is the same as on desktop, with 44px touch targets and 16px body text so iOS doesn't zoom in. Long-press a tab to rename it. The empty state suggests things to do with the active note.

Status vocabulary (one meaning everywhere)

working needs you error new reply done
  • A tab dot shows the most urgent state in that tab: needs you, then error, then working, then new reply.
  • An activity line uses the same icon set, just larger.

Tabs

  • Numbered by default. A renamed tab shows its name.
  • Rename by double-clicking, long-pressing on touch, or typing /rename <name>. Enter saves, Esc cancels, and an empty name brings the number back.
  • Up to 8 tabs. Tabs that don't fit go into the +N menu.

What changed vs today

  • The tabs move from the composer row to a header row.
  • Each tool call no longer gets its own card; one activity line covers the turn.
  • The approval modal becomes a card inside the turn.
  • The assistant reply has no bubble, the user's message has a soft one, and there's more vertical rhythm.
  • Model, context and permission mode stay in the toolbar but take less visual weight.
