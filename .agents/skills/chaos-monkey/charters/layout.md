Hunt for layout and accessibility problems.

Resize the main window to narrow widths (390, 500, 700) and back to wide. At each width, open the chat, menus, the slash-command menu, the approval modal, settings, and long assistant answers with code blocks and tables. Look for cut-off buttons, horizontal overflow (overflowX=true), overlapping elements, controls you cannot reach, and missing labels. Use the keyboard only for part of the run (Tab, Enter, Escape, arrow keys).
