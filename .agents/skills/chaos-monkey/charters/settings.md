Try to break the Agentic Chat settings.

Open settings, visit every tab, and change many values: toggles, dropdowns, number fields (try 0, negative, huge, and text in number fields), text fields (empty, very long, unicode, whitespace). After changes, close settings, use the chat, reload the plugin, and open settings again: check that values persisted or were rejected with clear feedback. Do not change the provider, model, base URL, or API key.
